# @littlesheep/mcp

预留 Model Context Protocol 适配边界，当前仅为骨架包。

## 职责与边界

- 公开入口是 `src/index.ts`。
- 未来负责把 MCP server 能力适配为 LS 的工具契约，不负责替代 Tool Manager 或权限系统。
- 禁止在没有生命周期、权限、超时、错误隔离和测试时把占位导出写成已完成功能。

## 依赖与数据

- 只允许依赖工具和公共契约；不得依赖 Electron renderer 或具体渠道。
- MCP 连接配置和凭证应归用户数据与安全存储管理，本包不保存明文凭证。

## 测试与修改定位

- 当前没有运行时实现测试；首次实现前必须先增加协议和失败路径特征测试。
- 新客户端从 `src/` 内部模块开始，稳定后再从 `src/index.ts` 导出。
