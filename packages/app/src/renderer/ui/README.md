# Renderer 通用 UI

这里放跨领域复用的交互基元，而不是具体业务页面。

- `presence.tsx`：淡入淡出、外部点击收回和存在状态。
- `floating-help.tsx`：延迟提示。
- `transient.ts`、`resize.ts`：临时菜单和拖动生命周期。
- `icons.tsx`：统一图标集合。

所有临时浮层应支持点击其他区域收回；新增转场必须使用统一时长、可中断清理和 reduced-motion 兼容路径。

`icons.tsx` 是无状态声明式图标集合，虽然略高于 300 行，但不包含业务状态、网络调用或跨域依赖；只有出现重复几何或独立图标家族时才按家族拆分。
