# Renderer Workspace

Workspace 呈现文件／目录、预览、Git review、浏览器标签和用户控制的终端。Main 与领域服务拥有文件系统访问、执行和路径授权。

开始页展示本机可用的 Shell，选择后进入终端；终端界面只保留输入输出，不展示状态栏、最近命令及新建／中断／重启／清空工具栏。切换标签保持会话，关闭终端标签结束其 Shell 进程；Shell 选择保存为下次打开偏好。终端内容直接铺满标签页，无额外卡片或内部工具栏。`node scripts/verify-workspace-terminal.mjs` 通过实际输入和进程身份检查关闭行为。

## 资源与权限边界

- 除非路径位于应用数据根内，用户选择的项目或目录仍是外部资源。选择用于显示不等于允许 Agent 扫描或执行。
- 公共权限选择为只读、工作区写入和完全访问。当前仅识别带 V2 版本标记的这三种会话权限；旧权限记录不迁移并会从会话索引清除。完全访问仍受 Main 硬拒绝和 Shell 审批策略约束。
- Renderer 通过 Local App API 请求文件和终端能力；不使用 Node 文件 API，也不把界面选中的路径当作授权。
- Main 重新检查 Agent shell 操作。用户自行打开和输入的交互终端属于用户操作，不弹 Agent 审批。

## 文件编辑与 review

- 文件树右键提供预览／展开、VS Code、显示文件位置及完整／相对路径复制；预览背景提供当前默认打开方式、位置和路径复制。编辑器保留自身的右键能力，选中文字与链接使用共享原生选区菜单。右键只展示操作，不自动打开、写文件或改变 Agent 授权；打开与显示位置仍由 Main 的工作区 API 校验。
- 标签右键提供关闭当前、其他、右侧和全部标签，以及文件路径／网页地址复制；关闭复用逐标签保存与拒绝处理，遇到拒绝或失败即停止批量操作，不自动丢弃草稿。终端右键通过当前 xterm 的选区与粘贴接口提供复制、粘贴和全选，异步读取剪贴板后重新核对终端身份与输入状态。

- 完整、未清洗的文件读取才可建立观察版本；partial、truncated、二进制预览或清洗后的读取不能授权覆盖。
- 修改已有文件前，Main 复核已观察的内容哈希。其他操作者已改文件时返回 stale／missing observation 并保留用户草稿。
- 保存与 review 响应有界且明确标记失败或截断。保存失败不能清空草稿。
- Git review 是仓库快照，不是单个脏文件的原子快照；opaque revision 和不稳定读取状态须保留，不得夸大一致性。
- Monaco 在文件查看、编辑和 Git review 之间共享；模型、预览与浏览器历史需有界。
- 打开方式以当前有效选择为唯一来源：下拉选项、主按钮图标／说明和点击目标同步变化，同窗口已打开的文件标签与其它窗口通过偏好事件同步；不存在或对当前文件不可用的目标回退到有效默认项。HTML 浏览器目标同样可记为当前选择，页面尚未运行时不可选。主按钮复用菜单选中项的图标，外部应用使用实际应用图标，缺失时使用打开应用图标；终端 Shell 使用各自的识别图形，启动动作由当前可用 Shell 决定。
- Monaco 与仍运行的 xterm 实例订阅应用外观变化并更新主题／字号，不因切换主题重建文件模型或终端会话；原始文档与 HTML 预览内容不强制反色。
- 「文件」标签不是第二份文件列表，而是左侧文件夹栏本身：同一套原地展开、选中高亮和打开文件交接，激活该标签时共享栏隐藏，屏幕上只有一棵文件夹树。加载、空结果和读取失败沿用文件导航的共享状态视图与重试动作。
- 标签栏只负责标签本身：横向溢出时它会滚动，而**新增（+）控件固定在头部右侧的窗口控件簇里**（与全屏／收起同一组），因此标签再多也不会被滚走或裁掉；头部同时给这一簇留出右边距，**标签列表滚到末尾时停在加号左侧**（4px 空隙），不会钻到加号底下（2026-10-03 反馈）。
- 文件表面**没有刷新按钮**：文件夹栏、打开的文件和 Git 审阅各自按自己的节奏重新读取——目录列表与 `file-stat` 每 4 秒一次、Git 快照 15 秒一次，且只在窗口可见、该标签就是屏幕上那一个时才跑（`use-workspace-auto-refresh.ts`）。别的程序写了文件，树会自动出现它；打开的文件在**没有未保存编辑**时自动重载，有编辑则仍走"磁盘已改动"提示由读者决定（2026-10-03 反馈）。浏览器标签的"刷新网页"不属于文件表面，保留。
- 开始页是关闭全部标签时的主页，不是标签；默认打开列表为空，旧的 `home` 标签在读取布局时移除。主页提供文件、审阅、终端和浏览器入口。

## 预览与验证

HTML 预览在打开时自动启动 Main 的有界 loopback preview service，并在 sandbox frame 里按浏览器语义运行页面脚本；frame 与 App 跨源，页面拿不到本窗口，`fileModifiedAt` 变化时原地重载而不换 URL（应用内浏览器标签因此不会失效）。相对资源只经该服务和路径检查提供。打开整页由读者决定：工具栏只提供应用内浏览器与系统浏览器两个入口，不自动跳转，也没有运行／重新加载／停止按键。

观察与写入使用 `verify:file-consistency-faults`、`verify:desktop-file-consistency`；HTML 预览使用 `verify:html-preview-baseline`，跨格式文件预览使用 `node scripts/verify-file-preview-content.mjs`。后者在隔离的真实 Electron 中核对冷启动、已预热编辑器和逐文件切换后实际显示的内容与磁盘一致，包括空文件；只读模型同步不作为用户修改写入草稿。Git 刷新使用 `verify:review-refresh-errors`；工作区与交互终端使用 `verify:conversation-workspace-scenarios`。这些入口证明不同边界。
