# Renderer Sidebar

Sidebar 呈现会话、项目和工作区导航。持久会话／项目状态来自 Main；本地展开、筛选和选择控件属于视图状态。

## 契约

- 切换会话会切换 transcript owner，并恢复对应草稿和工作区绑定。项目会话使用自己的工作区绑定，全局工作区只作默认值。
- 对话标题复用 `RunningPill` 的重命名与执行记录展示，由 ChatView 放在固定顶部区，与目录并列。正常对话布局关闭拖动和悬浮提示；点击查看执行记录，关闭按钮／Esc 返回标题焦点，记录数不代表并发后台任务数。复用组件保留可选浮动拖动能力，夹取算术仍在 `task-pill-drag.ts`。

- 新建、改名、置顶和归档通过对应 Main API；归档可以恢复，代表整理而非永久删除。
- 永久删除须说明真实影响并请求确认。删除失败时保留行和原因；快速重复提交不能派发重复操作。
- 搜索与键盘导航保持可见焦点目标；会话／项目用语与目标页面一致。
- 基础导航只呈现已接入的功能；“已安排”占位页仅保留设置搜索入口，避免日常导航承诺尚不可用的操作。
- 侧栏透明与圆角表面使用共享材质角色，不在浮动表面内再加一层模糊根节点。

状态 reducer 与搜索由局部测试覆盖；破坏性行为使用 `verify:deletion-confirmation`，真实会话和窗口行为使用 `verify:electron-ui-state-continuity`。
