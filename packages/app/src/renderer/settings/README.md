# Renderer Settings

设置工作区在首次打开时加载并挂载，之后保留导航与搜索状态；记忆树、插件和已安排模块按访问加载。字段搜索等待页面出现时，动画帧与定时器互相取消，避免慢加载期间重复累积定位回调。

Settings 呈现 Main 提供的配置与工具。它拥有页面导航和临时表单状态；Main 拥有持久值、密钥、Provider 检查和运行时效果。

## 契约

- 页面 id 是持久导航值。重组分类时保留现有 id，或提供明确迁移。
- 各页面用共享状态视图区分加载、成功但为空、不可用和失败。数据源允许时，刷新失败应保留仍可用的旧值。
- 外观页保存 Renderer 应用偏好（字号、主题、自定义配色与减少动态效果），独立于 Main 管理的 Provider、行为和权限配置；恢复默认只重置外观偏好，不重置对话显示密度或其他设置。模式缩略图与颜色行常驻显示，高级区包含字号、动态效果、显示密度和面板色调；颜色支持应用内调色板与十六进制输入，有效颜色立即应用并保存，不拦截低对比组合。旧配色没有前景色时继续自动选择可读文字色。
- 区分草稿、已保存和当前生效状态。Provider 编辑的敏感草稿只留在内存，不进入日志或搜索索引。编辑面板按“接口 / 模型”分组，被拒绝的字段在字段处就地说明；“获取模型”向草稿里的 API 地址直发一次 `GET /models`，只补模型 ID、不删除目录未列出的行，控件禁用时同句说明缺哪个事实。未填写的上下文窗口／最大输出／推理档位按 LS 的默认值使用（256K / 32K / 全部档位），所以不填也能直接用；这些默认值在卡片上标为“约 256K”并用警示色，**必须与用户自己声明的数值区分显示**，因为它们是假设而不是该模型的实测值。完整契约见 `docs/reference/custom-model-providers.md`。
- 调整预设和自定义颜色时，根级颜色令牌在 240ms 内平滑插值，颜色字段立即展示已保存目标值；首次启动和减少动态效果开启时立即应用。应用内调色板使用圆角浮层与色域，支持色域拖动／方向键、色相和 RGB 输入；Escape 关闭并归还焦点，浮层保持在窗口内。
- 设置搜索只索引安全、可见的字段标签和值，支持键盘移动、选择、焦点转移和 Escape 返回。密钥、cookie 和私有草稿永不索引。
- 禁用操作同时显示与禁用原因相同事实来源的说明。
- 总览的常用设置行复用侧栏的交互框（`border: 0` + `--radius-ui` + `--sidebar-interaction-hover`），并且**行与行之间不留间隙**：留了间隙时圆角高亮填不满所在单元格，上下会各露出一条相邻行的底色。相关约定由 `sidebar-section-toggle.test.ts` 与真实窗口的 `verify:settings-overview-row-hover` 共同固定。
- Token Usage 展示 Main 提供的有界每日用量 projection；不通过累加可见消息重算，并区分空、缺失、未来、partial 与真实零值。
- 共享视觉角色和圆角材质见 `ui/README.md`。

局部导航、搜索与 reducer 由设置测试覆盖；真实窗口入口包括 `verify:model-provider-ui`、`verify:provider-card-model-summary`、`verify:settings-overview-row-hover`、`verify:settings-navigation-terminology`、`verify:skills-catalog-states` 和 `verify:channel-entry-states`。用量聚合与隐私边界由 Main 测试覆盖。

设置路径按“入口、页面与返回目标”理解：从设置入口先到总览，侧栏或搜索打开目标页，返回沿用应用会话导航历史。侧栏分为“通用”（含外观）、“模型与行为”、“连接与扩展”（插件、技能、外部渠道）、“存储与环境”（归档、记忆树）及工作模块；已安排保留搜索入口。总览只列出模型供应商、外观、网络检索和存储与数据四个常用入口，不重复整套目录。本导航体系覆盖的目标名称包括记忆树、已安排、插件、归档、技能、外部渠道、外观、模型与行为、连接与扩展、存储与环境。
