# Renderer Composer

Composer 管理草稿输入、焦点、模型选择展示和 run 提交交互。Main 校验模型、权限和 Runtime 就绪状态；发送按钮可用不等于已获得执行权限。

## 契约

- 草稿与附件属于当前会话。切换会话后恢复对应草稿，不得把未发送内容带入另一会话的模型请求。
- 发送按钮、键盘提交和空对话提示共用同一个 readiness 判定。没有可用模型或执行能力时，本地拒绝并说明原因，不发送 run 请求。
- 模型／Provider 选择和密钥由 Main 持久化。敏感值只留在宿主密钥存储，不进入日志、搜索索引或 UI 摘要。
- 保留 IME 组合语义：Enter 确认候选词时不得发送。模态、审批或用户正在编辑其他字段时，焦点管理不能抢走焦点。
- 权限模式按对话持久化。Composer 展示并请求变更，Main 保存到当前会话；切换会话恢复各自模式，新草稿不会继承上一个会话的授权。
- V2 Agent Shell 每次都需单独确认，只提供拒绝或仅本次；Main 强制审批也不能复用已有会话授权。Shell 风险说明必须明确其在宿主运行且没有 OS 级隔离。
- 输入区在空白与已有消息时都浮于底部；正文在输入区后方滚动，并在输入框下边缘裁切。正文底部预留输入区高度，保证滚动到底时最后一条消息可读。就绪／模型阻塞原因位于独立状态行；控制行保持单行，窄列优先收缩路径和文字标签，停止与发送入口保持可见。宽度变化不增加草稿区域高度，换行后超出的内容内部滚动；输入内容变化时仍自动调整高度。textarea 有可访问名称与 Enter／Shift+Enter 说明。
- 输入卡使用随主题变化的 70% 半透明底色、20px 背景模糊和轻微饱和度增强；材质只作用于背景，输入文字和控件保持清晰。卡面、控件行和行内选择器一起构成对话区的控制面。
- 底部控件共用 `--composer-control-surface-size` 高度；模型、权限和工作区控件使用 12px 圆角。附加按钮为居中的 SVG 加号，取 `--radius-pill`，默认底色透明，仅悬浮时显示圆形底色。发送键是行内唯一的业务蓝实心圆形主操作（`--chat-business`），停止键用危险色角色。

定向测试覆盖提交就绪、草稿会话归属、焦点与模型可用性及审批范围；Electron 入口为 `verify:composer-send-gate`、`verify:composer-focus`、`verify:composer-draft-scope`、`verify:desktop-permission-v2`。源码测试不能证明真实 IME 行为；真实权限交互以隔离数据根中的 Electron 验收为准。
