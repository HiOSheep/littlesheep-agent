# @littlesheep/snapshot

为记忆数据提供快照索引、版本定位和回滚基元。

## 职责与边界

- 公开入口是 `src/index.ts`；存储适配在 `snapshot-memory-store.ts`，索引在 `snapshot-index.ts`。
- 负责快照元数据和恢复选择，不决定何时写入长期记忆或自动触发产品回滚。
- 禁止删除权威数据来换取快照空间，清理策略必须显式且有界。

## 依赖与数据

- 只依赖公共契约，被 Runner、CLI 和记忆服务消费。
- 快照属于用户数据，必须可定位来源层级和创建时间。

## 测试与修改定位

- 存储和索引测试与实现同目录。
- 修改排序或回滚语义时覆盖空仓库、过滤、损坏和重复时间戳。
