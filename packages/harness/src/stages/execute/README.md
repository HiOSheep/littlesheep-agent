# EXECUTE 内部边界

- `contracts.ts`：依赖、工具循环和输出清洗契约。
- `guidance.ts`：计划、TaskBook、单步骤提示和基础消息装配。
- `tool-loop.ts`：模型工具循环、权限、超时、中断、重复调用保护、结果清洗和会话证据写入。
- `failure-policy.ts`：步骤工具选择、阻断失败识别、失败分类和稳定结果排序。
- `runners.ts`：Legacy 与 TaskBook 两条执行调度路径，保护已完成步骤并发出运行事件。
- `final-reply.ts`：根据步骤结果按渐进式披露装配最终回复。

`../execute.ts` 只负责构建运行提示并选择执行路径。工具不能绕过权限门，失败步骤不能被最终回复覆盖为成功，恢复时已完成且不在重规划目标中的步骤不得重做。
