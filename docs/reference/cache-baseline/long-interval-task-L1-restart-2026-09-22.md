## 损失归因（实测分解）

每个会话的未缓存输入按三类归因：`coldStart`（该会话首个请求）、`rebuild`（单请求未缓存 ≥1024 tokens，
远高于供应商 128-token 块残差，说明提示词被重建而非追加）、`appendResidual`（追加步的新内容与块残差）。
